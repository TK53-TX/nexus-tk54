          Security decisions

          • ServiceNow secrets stay in the gateway's vault. The chat application never holds them.
          • Every message is inspected at the gateway. Prompt injection is ranked first in the OWASP Top 10 for LLM Applications.
          • Use a unique Message Auth token for each provider and keep the instance patched. AppOmni reported that a token shared across providers let outsiders reach the Virtual Agent API (CVE-2025-12420).
          • Retries reuse the request ID, and the flow checks the Incident correlation ID before it inserts, so one problem produces one ticket.
